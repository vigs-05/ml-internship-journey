 # Python OOPs: Inheritance & Magic (Week 2)

 **Goal:** Master code reuse, family trees (Inheritance), and Python's secret spells (Dunder Methods).

This folder moves beyond basic classes into advanced Object-Oriented Programming, forming the backbone of how ML libraries like Scikit-Learn are structured.

  Concepts Covered
- Single, Multilevel, and Multiple Inheritance
- The `super()` function
- Method Overriding & Polymorphism
- Dunder/Magic Methods (`__str__`, `__add__`)
- Operator Overloading
- Abstract Base Classes (ABC) & Interfaces

 Project Breakdown

| File Name | Concept Learned | Description |
| :--- | :--- | :--- |
| `vehicle.py` | Single Inheritance | Child class inheriting basic attributes from a Parent. |
| `tech_family.py` | Multilevel Inheritance | Grandparent -> Parent -> Child data passing using `super()`. |
| `smartphone.py` | Multiple Inheritance | A child inheriting from TWO parents simultaneously. |
| `animal_sounds.py` | Polymorphism | Objects of different classes responding to the same method name differently. |
| `shopping_item.py` | Dunder Methods | Hacking Python's `print()` function using `__str__`. |
| `complex_number.py` | Operator Overloading | Teaching custom objects how to do math (`+`) using `__add__`. |
| `payment_gateway.py` | Abstract Classes | Forcing child classes to follow strict rules using `@abstractmethod`. |
| `ecommerce_system.py` | **Week 2 Boss** | Combining all Week 1 & 2 concepts into a multi-class E-Commerce system. |
